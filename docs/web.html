Search the internet's images — free

This gallery has 14 images because we didn't index more. But the internet's images are already indexed — free, at billion scale, in the same CLIP space this repo teaches. LAION crawled ~5.5 billion image-text pairs from Common Crawl and released them CLIP-embedded (the safety-cleaned Re-LAION-5B); clip-retrieval serves nearest-neighbour search over them. So searching the web isn't a crawl you run — it's a query you send, and the index cost is $0 because someone already paid it and gave it away.

Results render in the same relevance grid and are watched by the same ranking-quality agent as the local search — 14 images or 5 billion, identical machinery.

How it's free — and how to run your own

Every piece is open-source and the dataset is metadata only (image URLs + captions + CLIP embeddings — the images are never redistributed, which is what keeps it lawful). To index the internet's images yourself, at your own scale, for the cost of compute and an SSD:

  1. img2dataset — download & resize the Re-LAION-5B image-text pairs from their URLs.
  2. open_clip — embed them (the same CLIP family; ~1,500 img/s on one consumer GPU).
  3. autofaiss — build a memory-mapped FAISS index that fits one machine (the full 5-billion-vector index serves from SSD in ~4 GB of RAM).
  4. clip-retrieval — serve KNN at POST /knn-service; paste its URL above.

Notes: use Re-LAION-5B (the 2024 safety-cleaned re-release), keep the NSFW/violence filters on, and match your query encoder to the index's CLIP model — the 5B index is ViT-L/14, so for this repo's ViT-B/32 space use a LAION-400M B/32 index (or self-host a B/32 index of Re-LAION). The client (web.js, the twin of web.py) is written to clip-retrieval's documented contract, so it talks to any of these unchanged.
